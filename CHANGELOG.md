## [1.0.0] - 2026-07-24

### 🚀 Initial Public Release — 100% Safe On-Demand AI Disk & Cache Optimizer

#### ✨ Added
- **Non-Overlapping AI Storage Scanner**: Scans `C:`, `D:`, and external drives for active AI coding footprints, prompt caches, and model weights with ancestor-descendant path deduplication.
- **Mandatory Automated Safety Restore Points**: Automatically creates a 100% reversible Safety Snapshot Restore Point before any file or cache is modified.
- **Windows Native Uninstaller Integration**: Triggers official Windows Add/Remove Programs (`appwiz.cpl` / `ms-settings:appsfeatures`) after creating a safety restore point.
- **Autonomous Clawbots & Scraper Scanner**: Detects installed and residual scraping engines including OpenDevin Clawbot, Crawl4AI Engine, and Playwright/Puppeteer headless binaries.
- **RAM Zombie Process Inspector**: Detects and safely terminates orphaned AI sidecars, MCP language servers, and high-RAM background processes.
- **Multi-Tab Persistent State**: Remembers your active tab across refreshes using `localStorage` & URL hashes.
- **Dual Desktop Packaging**: Supports both Setup Installers (`.exe` NSIS / `.dmg`) and zero-install Portable Executables (`.exe` / `.zip`).
- **100% On-Demand Security Guarantee**: Operates 100% offline with zero background services or startup daemons.
